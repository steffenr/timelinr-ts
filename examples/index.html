timelinr examples

  • Rail — horizontal timeline with a progress line and edge arrows
  • Stack — vertical layout with a position counter and up/down arrow keys
  • Tabs — compact year pills with dot pagination
  • List — vertical entries with icon medallions, windowed scroll
  • List (alternating) — the same rows, hung alternately off a centred rail
  • Autoplay — auto-advancing, pauses on hover, theme switcher
  • Fixed header — the same list under a fixed site header; navigating never scrolls the page
  • Auto size — the list timeline sized to its content via --tl-list-max-height: none, with a toggle against the default window
